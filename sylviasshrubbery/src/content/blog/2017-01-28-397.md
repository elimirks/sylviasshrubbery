A couple months ago, I made the switch from Vim to Emacs. However, I'm using Evil mode, so I still have all the nice Vim keybindings.

One of my biggest complaints about Emacs is ergonomics - "Emacs Pinky" is a legitimate concern:

{{< load-photoswipe >}}
{{< figure height="256" src="/images/misc/emacs-pinky.png" >}}

One solution is getting foot pedals or a fancy ergonomic keyboard like the Ergodox or Keyboardio, but I didn't want to commit to the investment just yet. Thus, [PinkyCtrls](https://github.com/elimirks/PinkyCtrls) was born! I forked an existing project that turned the space key into a control key if you held it, but worked as space if you tapped it (Space2Ctrl). However, with Space2Ctrl I found that I generally mistyped spaces a lot, since I tend to mash the space key soon after typing words. So I decided to shove the functionality onto the Caps Lock & Minus key (where the quote key is on QWERTY layouts).

After about 2 weeks of using this mod, I find it uncomfortable to use the normal control keys, and I have no problems with all the finger stress when using Emacs.

Note: The code in my PinkyCtrls repo is currently pretty ugly... I may clean it up eventually, but for now it does the job. If you want to fork PinkyCtrls to work on another layout or with other keys, let me know and I'll show you what you need to change!
